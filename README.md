# 潮水以南 (South of the Tides)

**主题**：一个县域男人36年的爱与遗憾  
**时间跨度**：2001-2048年  
**主角**：梁启潮

---

## 故事大纲

退伍军人梁启潮回到家乡南方小县城，父亲梁大顺是烧窑工，父子日子清贫。启潮听说县里要搞开发区征地，决定去县城做工程材料生意。老爹最初反对，最后默认可怜天下父母心，给了3000块学费。启潮骑着摩托消失在晨雾里...

---

## 感情线

### 林晚棠
- **2001年**：村里庙会，启潮对晚棠一见钟情
- **2002-2004年**：热恋，枣树下私定终身
- **2005年**：启潮去县城打工，晚棠赌气嫁给镇上商人
- **2013年**：云栖府工地重逢，晚棠开建材店，暗中帮启潮介绍客户
- **2020-2022年**：晚棠拿出积蓄帮启潮渡過债务危机
- **2024年**：晚棠主动退出，"我不再是当年的晚棠"
- **结局**：出国陪伴女儿读书

### 映真
- **2006年**：县医院，启潮看病认识护士映真
- **2007年**：结婚，映真不嫌启潮穷
- **2016年**：启潮经常去看晚棠，映真隐约知道
- **2025年**：照片事件，映真回娘家
- **最后**：陪伴启潮一生

### 沈晓燕（沈知秋）
- **2021年**：记者采访启潮
- **暗涌**：沈晓燕对启潮有欣赏，启潮保持距离
- **结局**：调去省城，最后采访成为告别

---

## 事业线

### 建材期（2012-2015）
- 云栖府项目：饭局屈辱、杜总跑路、债主泼油漆、工人堵门
- 挖到第一桶金，但80万要不回来

### 房地产合作期（2015-2020）
- 和周霆：真正友谊，一起扛过事，后来翻脸
- 竞争：抢项目、互相使绊子
- 事故：工人摔伤，50万私了

### 独立期（2020-2025）
- 单干艰难：找项目、陪笑脸、送礼
- 房地产下滑：云栖府二期差点翻车
- 转型：建立物流公司

### 疫情期（2023）
- 封城，物流中断
- 运送物资、冒险出门

### 短视频/退休期（2030-2048）
- 跟上时代：直播、短视频
- 退休后的生活

---

## 戏剧冲突

- **2014年**：启潮差点出轨（没发生，但映真知道）
- **2029年**：婚姻最危险，提到离婚
- **2041年**：周霆起诉，官司纠缠
- **2043年**：洪水损失
