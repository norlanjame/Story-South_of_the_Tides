# 潮水以南 (South of the Tides)

**主题**：欲望与责任的博弈——一个县域男人在时代洪流中的挣扎与救赎

**副标题**：当金钱、权力、欲望呼啸而来，守住本心有多难

**时间跨度**：2001-2048年  
**主角**：梁启潮（2001年23岁退伍）

---

## 核心主题探讨

1. **城乡流动中的身份认同**：退伍军人回到家乡，却发现自己既回不到传统农民的身份，也无法真正融入城市

2. **原始积累的代价**：第一桶金的背后，是尊严的屈服、良心的不安、人情的消耗

3. **婚姻中的背叛与原谅**：当丈夫的情感天平倾向旧爱，原配妻子是选择隐忍还是决裂

4. **阶层跃迁的困境**：拼命想要跨越的阶层鸿沟，最终发现努力换来的可能是更大的空虚

5. **故土与远方**：走出去的人成了故乡的陌生人，留下的成了时代的弃儿

---

## 人物设定

### 梁启潮
- 1978年出生，2001年23岁退伍
- 退伍前在青海当汽车兵（青藏线）
- 退伍后被安排在镇砖瓦厂开拖拉机
- 父亲梁大顺：烧窑工，58岁，脾气倔
- 母亲：55岁，慈祥节俭
- **性格**：倔强、不甘平庸、有担当，但有时自私、逃避

### 林晚棠
- 1979年出生，比启潮小1岁
- 村小学代课老师
- **性格**：温柔痴情、坚韧、为爱可以牺牲一切
- 与启潮青梅竹马，**退伍前已相恋多年**

### 映真
- 县医院护士
- 2006年与启潮相识
- **性格**：善良务实、包容坚忍、外柔内刚

### 沈晓燕（沈知秋）
- 记者，2021年采访启潮
- **性格**：理性独立、追求真相、有理想主义

### 周霆
- 启潮的合作伙伴/对手
- 房地产商人
- **性格**：精明能干、亦敌亦友

## 详细时间线

### 第一阶段：退伍归来（2001年9月）

**剧情**：
- 启潮2001年9月退伍，从青藏线回到家乡南江县
- 退伍前已和晚棠相恋多年（入伍前就在一起）
- 回家后父子因去县城打工发生冲突
- 老党梁大顺反对，父子拍桌子
- 最后老党默认，给了3000块学费
- 晚棠来送别，两人难舍难分
- 启潮骑着摩托消失在晨雾里

**主题**：乡土情怀 vs 城市欲望的第一次碰撞

### 第二阶段：县城闯荡（2001-2005）

**剧情**：
- 启潮在县城找到给建材老板开车的工作
- 晚棠在村里小学当代课老师
- 两人异地，通过写信联系
- 2004年：启潮第一次做生意被骗，血本无归
- 2005年：落魄回家，晚棠被母亲逼婚
- 晚棠赌气嫁给镇上商人
- 两人分手

**主题**：贫困是如何杀死爱情的

### 第三阶段：建材创业（2006-2012）

**剧情**：
- 2006年：启潮在县医院看病认识映真
- 2007年：启潮和映真结婚，映真不嫌启潮穷
- 2008年：汶川地震，启潮去当志愿者
- 2008-2012年：启潮开始做建材生意
- 2012年：云栖府项目，挖到第一桶金
- 但80万工程款要不回来

**主题**：婚姻是选择爱情还是选择合适

### 第四阶段：事业起伏（2013-2020）

**剧情**：
- 2013年：云栖府工地重逢晚棠
- 晚棠丈夫赌博欠债离婚，她自己开建材店
- 启潮和晚棠再次产生交集
- 2015年：认识周霆，开始合作
- 2016年：沈晓燕采访启潮，互相欣赏
- 2019年：工人摔伤事故，50万私了
- 2020年：疫情，工地停工

**主题**：旧爱重逢，是命运的安排还是命运的捉弄

### 第五阶段：债务危机（2021-2025）

**剧情**：
- 2021年：房地产寒冬，债务危机
- 启潮资金链断裂，债主上门
- 晚棠拿出所有积蓄帮忙（20万）
- 映真发现端倪，但选择信任
- 2022年：启潮差点出轨（未遂）
- 2023年：疫情封城，启潮冒险运送物资
- 2024年：晚棠主动退出
- 2025年：照片事件爆发，映真回娘家

**主题**：婚姻中的信任危机与自我救赎

### 第六阶段：晚年（2026-2048）

**剧情**：
- 2026年：启潮解释清楚，映真回家
- 2029年：婚姻最危险，提到离婚
- 2030年：短视频兴起，启潮开直播
- 2035年：儿子小满结婚
- 2041年：周霆起诉，官司纠缠
- 2043年：洪水损失
- 2048年：启潮去世，映真陪伴

**主题**：一生的选择，是对是错
