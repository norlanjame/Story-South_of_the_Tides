# 潮水以南 (South of the Tides)

**主题**：被潮水裹挟的人——县域经济的边缘命运与普通人的时代漂流

**基调**：
- 南方、湿热、氤氲
- 边缘、基层、灰色地带
- 流动、漂浮、无法自主
- 时代洪流下个体的无力感

**副标题**：2001-2048，一个退伍兵的小城漂流记

---

## 主题解读

"潮水以南"意味着：

1. **地理意象**：长江以南的县级市，潮湿、多雨、闷热
2. **经济边缘**：不属于大城市，不是经济中心，是被忽视的角落
3. **时代洪流**：改革开放的浪潮冲击着每一个普通人
4. **个体命运**：像水中的浮萍，无法自主，只能随波逐流
5. **欲望挣扎**：想要上岸，却被潮水一次次打回

**核心情绪**：
- 压抑中的喘息
- 困顿中的希望
- 妥协中的坚守
- 失去中的得到

---

## 时代背景

- **2001年**：中国加入WTO，经济起飞
- **2008年**：汶川地震，金融危机
- **2012年**：十八大召开
- **2016年**：供给侧改革
- **2020年**：新冠疫情
- **2023年**：后疫情时代

每一代人都有自己的困境，启潮这代人见证了中国经济的高速发展，也承受了代价。

---

## 人物设定

### 梁启潮
- 1978年出生，2001年23岁退伍
- 退伍前在青海当汽车兵（青藏线）
- 退伍后被安排在镇砖瓦厂开拖拉机
- 父亲梁大顺：烧窑工，58岁
- 母亲：55岁
- **性格**：倔强、不甘、善良、有担当
- **命运**：想要闯出一片天地，却被时代裹挟

### 林晚棠
- 1979年出生
- 村小学代课老师
- **与启潮青梅竹马，退伍前已相恋多年**
- **性格**：温柔、痴情、坚韧
- **命运**：被母亲嫁给商人，婚姻不幸

### 映真
- 县医院护士
- 2006年与启潮相识
- **性格**：善良、务实、坚忍
- **命运**：包容丈夫的一切，最终白头偕老

### 沈晓燕
- 记者
- 2021年采访启潮
- **性格**：理性、独立
- **命运**：欣赏启潮，但保持距离
