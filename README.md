# 潮水以南 (South of the Tides)

**主题**：一个县域男人36年的爱与遗憾  
**时间跨度**：2001-2048年  
**主角**：梁启潮（2001年23岁退伍）

---

## 人物设定

### 梁启潮
- 1978年出生，2001年23岁退伍
- 退伍前在青海当汽车兵（青藏线）
- 退伍后被安排在镇砖瓦厂开拖拉机
- 父亲梁大顺：烧窑工，58岁，脾气倔
- 母亲：55岁，慈祥节俭

### 林晚棠
- 1979年出生，比启潮小1岁
- 村小学代课老师
- 温柔贤惠，与启潮青梅竹马
- 退伍前已和启潮相恋（2001年前）

### 映真
- 县医院护士
- 2006年与启潮相识

### 沈晓燕（沈知秋）
- 记者，2021年采访启潮

---

## 详细时间线

### 第一阶段：退伍归来（2001年）

**剧情**：
- 启潮2001年9月退伍，从青藏线回到家乡南江县
- 退伍前已和晚棠相恋（入伍前就开始）
- 回家后父子因去县城打工发生冲突
- 老爹梁大顺反对，父子拍桌子
- 最后老党默认，给了3000块学费
- 启潮骑着摩托消失在晨雾里

**本章要点**：
- 退伍仪式、战友送别
- 父子冲突的细节
- 晚棠来送别的场景
- 摩托出发场景

### 第二阶段：县城闯荡（2001-2005）

**剧情**：
- 启潮在县城找到给建材老板开车的工作
- 晚棠在村里小学当代课老师
- 两人异地，通过写信联系
- 2005年：启潮生意失败，落魄回家
- 晚棠被母亲逼婚，赌气嫁给镇上商人

**本章要点**：
- 启潮在县城的工作
- 和晚棠的通信
- 第一次生意失败

### 第三阶段：建材创业（2006-2012）

**剧情**：
- 2006年：启潮在县医院看病认识映真
- 2007年：启潮和映真结婚
- 2008-2012年：启潮开始做建材生意
- 2012年：云栖府项目，挖到第一桶金

**本章要点**：
- 启潮和映真相识相恋
- 建材生意起步
- 云栖府项目细节

### 第四阶段：事业起伏（2013-2020）

**剧情**：
- 2013年：云栖府工地重逢晚棠
- 晚棠丈夫赌博欠债离婚，开建材店
- 启潮和晚棠再次产生交集
- 2015-2020年：和周霆合作
- 2016年：沈晓燕采访启潮
- 2020年：疫情，债务危机

**本章要点**：
- 晚棠线重启
- 周霆竞争
- 沈晓燕出现
- 疫情冲击

### 第五阶段：债务危机（2021-2025）

**剧情**：
- 2021年：债务危机最严重
- 晚棠拿出积蓄帮忙
- 映真发现端倪，选择信任
- 2024年：晚棠主动退出
- 2025年：照片事件，映真回娘家

**本章要点**：
- 三角关系最微妙
- 晚棠退出
- 婚姻危机

### 第六阶段：结局（2025-2048）

**剧情**：
- 2025年：启潮解释清楚，映真和好
- 2029年：婚姻最危险，提到离婚
- 2030-2040年：短视频/直播
- 2041年：周霆起诉，官司
- 2043年：洪水损失
- 2048年：启潮去世

---

## 核心情节

### 父子冲突
- 启潮提出去县城做工程材料生意
- 老党强烈反对，认为农民就该种地
- 父子拍桌子，激烈争吵
- 最后老党心疼儿子，默认并给3000块

### 感情线

**启潮和晚棠**：
- 青梅竹马，退伍前就相恋
- 退伍后异地，2005年晚棠赌气嫁人
- 2013年云栖府重逢
- 晚棠暗中帮启潮介绍客户
- 2024年晚棠主动退出

**启潮和映真**：
- 2006年县医院相识
- 2007年结婚，映真不嫌启潮穷
- 2016年后启潮常去看晚棠，映真隐约知道
- 2025年照片事件爆发
- 最后陪伴一生

**启潮和沈晓燕**：
- 2021年记者采访
- 互相欣赏，止于分寸
- 调去省城，告别

### 事业线

**建材期（2008-2015）**：
- 云栖府项目细节
- 杜总跑路
- 债主泼油漆
- 80万要不回来

**合作期（2015-2020）**：
- 和周霆：从合作到翻脸
- 抢项目竞争
- 工人摔伤，50万私了

**独立期（2020-2025）**：
- 房地产下滑
- 物流公司转型

**疫情期（2023）**：
- 封城
- 冒险送物资
